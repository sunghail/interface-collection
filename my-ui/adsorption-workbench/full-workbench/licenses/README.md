# 권리 기록

내 UI의 작성자: sunghail. 직접 작성한 코드에 새 공개 라이선스를 임의로 부여하지 않았습니다.
현재 metadata의 `unverified / UNSPECIFIED`는 직접 작성한 코드의 재사용 조건이 미정임을 뜻합니다.
모든 외부 코드가 출처 미상이라는 의미는 아닙니다.

| 합성 preview와 화면 캡처 | 이 UI 아카이브 작업에서 생성 | 합성 수식·데이터만 사용 | preview wrapper 별도 추가 |

dependencies.json은 설치된 package-lock 패키지들의 라이선스 파일 목록이며 번들에 모두 포함되었다는 의미는 아닙니다.
개인 UI의 라이선스 미정과 각 외부 패키지의 기존 라이선스를 구분하여 확인하세요.
