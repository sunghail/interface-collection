# Reference UI

외부 제작 UI의 디자인 참고 아카이브입니다. 저장한 자료의 제작자는 원저작자입니다.

- 저장 위치: `reference-ui/<primary-type>/<creator-slug>--<ui-slug>/`
- 대표 유형은 [공통 분류](../docs/taxonomy.md) 중 하나입니다.
- 하나의 항목에 여러 유형·태그를 붙이고, 같은 자료를 유형마다 중복 저장하지 않습니다.
- 기본 보관 범위는 링크, 출처, 내 관찰 메모입니다.
- screenshot, GIF, HTML, 소스는 보관·공유 근거를 확인한 범위에서만 추가합니다.
- 소스 보관이 필요한 경우에만 `source/`를 추가하고 원본 commit, 수정 범위, 라이선스를 적습니다.
